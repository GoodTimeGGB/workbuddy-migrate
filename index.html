WorkBuddy 迁移工具

在两台电脑之间迁移 WorkBuddy 的空间、会话与任务数据 · 支持 Windows / macOS / Linux · 支持跨系统迁移

⬇️ 下载 v1.0.0（约 0.6 MB）
SHA256：4d96ce62…ab34e8025 · 校验文件

它是什么

把旧电脑上 WorkBuddy 的注册信息、会话、任务、文件内容（可选含完整对话记录）打包成一个 zip，传到新电脑一键导入。导入前有完整预览与自动备份，任何情况下不会删除目标电脑已有数据。

  • ✅ 跨系统迁移：公司 Windows 导出 → 家里 Mac 导入（自动重写路径前缀）
  • ✅ 纯 Python 标准库实现，零第三方依赖；未装 Python 时启动脚本会引导一键安装
  • ✅ 全程本地运行，不上传任何数据到云端

快速开始

下载后解压 zip 到任意文件夹（Windows 解压前建议右键 → 属性 → 解除锁定）
Windows双击 scripts/windows/start.bat，自动打开浏览器
macOS终端执行 chmod +x scripts/macos/*.sh scripts/macos/*.command 后双击 start.command
Linuxbash scripts/linux/start.sh

使用期间请保持命令行窗口开启（可最小化）。详细图文步骤见 在线使用说明。

环境要求与常见问题

  • Python 3.8+（官网下载 · 慢可用华为镜像）；没有也没关系，双击启动后会引导安装
  • 黑窗口一闪而过？看同目录 start.log；或运行 scripts/windows/diagnose.bat 一键诊断
  • 页面显示"正在扫描本机空间"是正常现象，首次扫描大目录需要几十秒
